{# Macros for printing a number. Kept out of base.html because importing from a template also runs its top level, and base.html is the layout. These exist because this site's one job is never to state a figure without its evidence. figure() prints a value above the sample it rests on. absent() prints a dashed rule and the reason. Every number goes through one of the two, so a suppressed median cannot leak out as a blank cell that reads as zero. #} {% macro figure(value, basis=None) %} {%- if value is none -%} {{ absent(basis or "not measured") }} {%- else -%} {{ value }}{% if basis %}{{ basis }}{% endif %} {%- endif -%} {% endmacro %} {% macro absent(reason) %} {{ reason }} {% endmacro %} {% macro bar(share) %} {% endmacro %} {# Charts, as inline SVG. No chart library on purpose. Chart.js and its peers default to a plotted frame, gridlines, a legend and hover tooltips. Every one of those is ink that carries no data, which is the definition of chartjunk, and a legend forces the eye to jump between the key and the mark instead of reading the mark directly. So: one baseline rule, direct labels on the marks, no frame, no grid, no legend. Cleveland and McGill ranked graphical perception tasks and put position on a common scale first and length second, with angle and area far behind, which is why everything here is a bar or a dot and there is no pie anywhere in this project. #} {# Horizontal bars. Length from a common zero, sorted, value labelled on the mark. Sorting is not cosmetic: an unordered bar chart makes the reader do the ranking themselves. #} {% macro hbars(rows, max_value, unit="") %}
{% for r in rows %}
{{ r.label }} {{ r.display }}{{ unit }}
{% endfor %}
{% endmacro %} {# A dot on a common 0..max scale. Used where the quantity is a rate or a level rather than a count, because a bar from zero implies the zero is meaningful and for a median salary it is not. #} {% macro dots(rows, max_value, unit="") %}
{% for r in rows %}
{{ r.label }} {% if r.value is not none %} {% else %}not measured{% endif %} {% if r.value is not none %}{{ r.display }}{{ unit }}{% else %}–{% endif %} {{ r.basis }}
{% endfor %}
{% endmacro %} {# Two rates side by side on one scale. The whole point of the panel is the gap between them, so they share an axis and the gap is stated in words too. #} {% macro compare(a_label, a_value, b_label, b_value, unit="%") %}
{% for it in [(a_label, a_value, true), (b_label, b_value, false)] %}
{{ it[0] }} {{ '%.1f'|format(it[1]) }}{{ unit }}
{% endfor %}
{% endmacro %}
