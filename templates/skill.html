How the split is decided

Two separate signals. Asked for together comes from real job ads: how often the pair appears in one posting, divided by how common each skill is, so it means "unusually often" rather than "common". Description overlap comes from embedding a one-line description of each skill with the name and the vendor stripped out, so the comparison is about what the tool does rather than who makes it.

Sharing ads and describing the same kind of thing means substitutes, like PyTorch and TensorFlow. Sharing ads while describing different things means complements, like Docker and Kubernetes. Co-occurrence alone cannot tell these apart, because an ad saying "X and Y" looks identical to one saying "X or Y".

The cut is a fixed threshold on description overlap, not a trained model. Three description groups are written identically after the vendor is stripped (AWS, Azure and GCP; PyTorch and TensorFlow; MySQL and PostgreSQL), so those pairs score 1.00 and the embedding did no work on them.
